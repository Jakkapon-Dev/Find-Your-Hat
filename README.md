# Find Your Hat (JavaScript Terminal Game)

โปรเจกต์มินิเกมบน Terminal เขียนด้วย **Node.js** จำลองเขาวงกตที่ผู้เล่นต้องเดินทางเพื่อตามหาหมวก (`^`) และหลบหลุม (`O`)

---

## วิธีการรันโปรเจกต์

ต้องติดตั้ง [Node.js](https://nodejs.org/) ในเครื่องก่อน แล้วเปิด Terminal ในโฟลเดอร์นี้และพิมพ์:

```bash
node Find-Your-Hat.js
```

---

## วิธีการเล่นและการควบคุม

ใช้คีย์บอร์ดพิมพ์ตัวอักษรแล้วกด **Enter**:

- `w` : เดินขึ้น (Up)
- `s` : เดินลง (Down)
- `a` : เดินซ้าย (Left)
- `d` : เดินขวา (Right)
- `q` : ออกจากโปรแกรม (Quit)

### สัญลักษณ์ในเกม:
- `*` : ตำแหน่งปัจจุบันของคุณ / เส้นทางที่เดินผ่านมาแล้ว
- `^` : หมวกเป้าหมาย (เดินไปถึงเพื่อชนะ)
- `O` : หลุม (ถ้าเดินตกหลุมจะ Game Over ทันที)
- `·` : ทางเดินสนามโล่ง

---

## โครงสร้างและการทำงานของโค้ด

โค้ดหลักทั้งหมดอยู่ในไฟล์ `Find-Your-Hat.js` โดยแบ่ง logic การทำงานออกเป็นส่วนๆ ดังนี้:

### 1. `readline` & Terminal Setup
ใช้ built-in module `readline` ของ Node.js เพื่อรอรับ input (w/a/s/d) จากผู้เล่นผ่าน Standard I/O

### 2. Colors & Styling
ใช้รหัส ANSI Color พื้นฐาน (`\x1b[...]`) เพื่อไฮไลท์สีตัวละคร เช่น สีฟ้าสำหรับผู้เล่น, สีทองสำหรับหมวก, และสีแดงสำหรับหลุมอันตราย

### 3. Class `Field`
โครงสร้างแบบ OOP จัดการสถานะและระบบเกม:

- **`constructor(field)`**: เก็บ 2D Array ของสนาม และตำแหน่งเริ่มต้นของผู้เล่นที่พิกัด `(0, 0)` พร้อมตัวนับจำนวนก้าว `steps`
- **`print()`**: เคลียร์หน้าจอ (`console.clear()`) แล้ววาดแผนที่พร้อมเส้นขอบตารางและสถิติปัจจุบัน
- **`playTurn()`**: ลูปการเล่นหลัก รับ input จากผู้เล่น อัปเดตพิกัด `x`, `y` และเช็คเงื่อนไขแพ้-ชนะ
- **`isInBounds()`**: เช็คว่าพิกัดปัจจุบันยังอยู่ข้างในขอบเขตแผนที่หรือไม่
- **`isHole()` / `isHat()`**: ตรวจสอบว่าพิกัดที่เดินไปเหยียบโดนหลุมหรือหมวก
- **`askPlayAgain()`**: เมื่อจบเกม (ไม่ว่าจะชนะหรือแพ้) จะถามว่าต้องการเริ่มเล่นใหม่หรือไม่
- **`Field.generateField(height, width, percentage)`**: ฟังก์ชัน Static สำหรับสร้าง 2D Array สุ่มวางตำแหน่งหมวก และสุ่มกระจายหลุมตามเปอร์เซ็นต์ที่กำหนด (ค่าเริ่มต้น 20%)
