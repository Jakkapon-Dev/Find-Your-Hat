# Find Your Hat (JavaScript Terminal Game)

โปรเจกต์มินิเกมบน Terminal เขียนด้วย **Node.js (Object-Oriented Programming)** จำลองเขาวงกตที่ผู้เล่นต้องเดินทางเพื่อตามหาหมวก (`^`) และหลบหลุม (`O`)

---

## 🚀 วิธีการรันโปรเจกต์

ต้องติดตั้ง [Node.js](https://nodejs.org/) ในเครื่องก่อน แล้วเปิด Terminal ในโฟลเดอร์นี้และพิมพ์:

```bash
node Find-Your-Hat.js
```

---

## 🎮 วิธีการเล่นและการควบคุม

ใช้คีย์บอร์ดพิมพ์ตัวอักษรแล้วกด **Enter**:

- `w` : เดินขึ้น (Up - เรียกเมธอด `moveUp()`)
- `s` : เดินลง (Down - เรียกเมธอด `moveDown()`)
- `a` : เดินซ้าย (Left - เรียกเมธอด `moveLeft()`)
- `d` : เดินขวา (Right - เรียกเมธอด `moveRight()`)
- `q` : ออกจากโปรแกรม (Quit)

### สัญลักษณ์ในเกม:
- `*` : **Actor (ผู้เล่น)** / ตำแหน่งปัจจุบันและเส้นทางที่เดินผ่านมาแล้ว
- `^` : **Hat (หมวกเป้าหมาย)** เดินไปถึงเพื่อชนะ
- `O` : **Hole (หลุมพราง)** ถ้าเดินตกหลุมจะ Game Over ทันที
- `·` : **Field (พื้นที่สนามโล่ง)** ทางเดินปลอดภัย

## 🏗️ โครงสร้าง Class Method และการทำงาน

โค้ดหลักอยู่ในไฟล์ `Find-Your-Hat.js` โดยออกแบบตามหลัก OOP:

### 1. Class Methods
- **`constructor(field)`**: รับตารางแผนที่ 2D Array เข้ามา และค้นหาพิกัดเริ่มต้นของ Actor
- **`moveUp()`**: ขยับตำแหน่งขึ้นด้านบน (`this.y -= 1`)
- **`moveDown()`**: ขยับตำแหน่งลงด้านล่าง (`this.y += 1`)
- **`moveLeft()`**: ขยับตำแหน่งไปทางซ้าย (`this.x -= 1`)
- **`moveRight()`**: ขยับตำแหน่งไปทางขวา (`this.x += 1`)
- **`print()`**: เคลียร์หน้าจอและวาดตารางแผนที่พร้อมเส้นขอบและสีสัน
- **`playTurn()`**: ลูปการเล่นหลัก รับ input และตรวจสอบผลลัพธ์
- **`isInBounds()`, `isHole()`, `isHat()`**: ฟังก์ชันตรวจสอบสถานะพิกัด
- **`askPlayAgain()`**: จัดการ Replay เมื่อจบเกม

### 2. Random Spawn (สุ่มตำแหน่ง)
- **`Field.generateField(height, width, percentage)`**:
  - สุ่มตำแหน่งเกิดของ **Actor (`*`)** บนกระดาน
  - สุ่มตำแหน่งของ **Hat (`^`)** โดยไม่ให้ซ้ำกับ Actor
  - สุ่มกระจายตำแหน่งของ **Holes (`O`)** ตามสัดส่วนความยาก (Default 20%) โดยไม่ทับ Actor หรือ Hat

### 3. Game Logic Messages
- **ชนะ**: `🎉 You found the hat! You win!`
- **ตกหลุม**: `💀 You fell into a hole! Game over.`
- **ออกนอกกระดาน**: `🚫 You went out of bounds! Game over.`
